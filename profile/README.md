<h1>Our Products</h1>

<div>
  <h2>
    <a href="https://github.com/MicYou-Dev/MicYou">MicYou</a> <- Click to Visit
  </h2>
  Turns your phone into a high-quality microphone for your PC: a native Android client and a desktop server for Windows, Linux and macOS.

  <hr>

  <h3>Features</h3>
  <ul>
    <li><strong>Connection Modes</strong>: Wi-Fi, USB (ADB on Android, usbmuxd on iOS), and Web mode from any mobile browser by scanning a QR code.</li>
    <li><strong>Audio Processing</strong>: AI and traditional noise suppression, acoustic echo cancellation (AEC), dereverberation, equalizer, automatic gain control (AGC), and voice activity detection (VAD).</li>
    <li><strong>Cross-Platform</strong>:</li>
      <ul>
        <li><strong>Android Client</strong>: Modern Material 3 interface with dark and light themes.</li>
        <li><strong>iOS Client</strong>: Native SwiftUI app, see <a href="https://github.com/MicYou-Dev/MicYou-iOS">MicYou for iOS</a> below.</li>
        <li><strong>Desktop Server</strong>: Full GUI, lightweight CLI, or interactive TUI on Windows, Linux and macOS.</li>
      </ul>
    <li><strong>Virtual Microphone</strong>: Shows up as a system microphone through VB-CABLE on Windows, PipeWire on Linux, or BlackHole on macOS.</li>
    <li><strong>Monitoring</strong>: Live audio level, bitrate, latency, jitter, and packet loss.</li>
    <li><strong>Plugins</strong>: Native and WASM plugins with an in-app marketplace for DSP nodes, soundpads, and control widgets.</li>
  </ul>

  <h2>
    <a href="https://github.com/MicYou-Dev/MicYou-iOS">MicYou for iOS</a> <- Click to Visit
  </h2>
  The native iPhone and iPad client for the MicYou desktop server, built with SwiftUI. Requires iOS 18 or later and is installed by sideloading.

  <hr>

  <h3>Features</h3>
  <ul>
    <li><strong>Connection</strong>: Finds computers on the network over Bonjour, or connects by IP address or over a USB cable.</li>
    <li><strong>Audio</strong>: Opus or 16-bit PCM at up to 48 kHz, mono or stereo, with input gain, a peak limiter, and optional voice processing.</li>
    <li><strong>Background Streaming</strong>: Keeps streaming with the screen locked, with a Live Activity and Dynamic Island for mute and disconnect.</li>
    <li><strong>Link Quality</strong>: Shows the round trip time and packet loss measured by the desktop.</li>
    <li><strong>Shortcuts</strong>: Connect, disconnect, and mute from Shortcuts or <code>micyou://</code> links.</li>
  </ul>
